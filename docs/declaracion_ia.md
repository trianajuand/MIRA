# Declaración de uso de inteligencia artificial generativa

Durante el desarrollo del prototipo se utilizó **Claude (Anthropic), mediante Claude Code**, como herramienta de apoyo para el equipo. Su función fue servir como asistente en la revisión del código, la identificación de posibles errores y la orientación durante el proceso de desarrollo.

## Herramienta utilizada

Claude (Anthropic), a través de Claude Code.

## Para qué se usó

- Revisar el código desarrollado por el equipo e identificar posibles errores o inconsistencias.
- Recibir orientación para solucionar problemas técnicos durante la implementación del prototipo.
- Analizar el funcionamiento de algunas funcionalidades, como la detección del parpadeo, la calibración y el teclado de barrido.
- Apoyar la organización del código en diferentes archivos y módulos.
- Revisar y mejorar la documentación del proyecto, incluyendo el README y el borrador del protocolo de validación.

## Qué definió y desarrolló el equipo

- El problema, el usuario objetivo, las hipótesis y el diseño general del sistema, establecidos en la primera entrega.
- La lógica de funcionamiento del prototipo y sus funcionalidades principales.
- La implementación y adaptación del código, tomando las decisiones necesarias durante el desarrollo.
- Las decisiones de diseño, como las dos distribuciones de teclado, la personalización de frases rápidas por parte del cuidador y la organización modular del proyecto.
- La selección de las funcionalidades que se incluirían en el prototipo final.

## Límites

Claude Code se utilizó únicamente como herramienta de asistencia y consulta durante el desarrollo. Las decisiones de diseño, la implementación, las pruebas y la validación del prototipo estuvieron a cargo del equipo. Los resultados de validación presentados en el informe corresponden a pruebas realizadas por el equipo con personas reales; la herramienta de inteligencia artificial no generó ni modificó esos datos.
