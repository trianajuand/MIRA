# MIRA

Comunicador por parpadeo voluntario para personas que no pueden hablar ni moverse. Usa la cámara web del computador para detectar el parpadeo intencional y un teclado de barrido en pantalla para formar mensajes que se reproducen en voz alta.

Proyecto de innovación tecnológica · Gestión de Tecnología e Innovación · Ingeniería de Sistemas, Universidad El Bosque, 2026-2.
